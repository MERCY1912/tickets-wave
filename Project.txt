🎯 Цель проекта

Создать локальное desktop-приложение для Support Manager, которое позволяет:

вести тикеты по проекту

быстро писать заметки

управлять статусами

назначать теги

ставить напоминания

получать автоматические уведомления

использовать локального ИИ ассистента

не отправлять данные в интернет

Все данные хранятся только локально.

🔔 Напоминания

Поддерживаются:

Ручные

пользователь устанавливает дату и время

Автоматические

если тикет без апдейтов N дней

если статус Waiting Client более N дней

если приоритет высокий и нет активности

если тикет давно открыт

Уведомления должны:

красиво всплывать

иметь кнопки действий

быть ненавязчивыми

🤖 ИИ ассистент — ключевая часть

ИИ — не чат-бот.

ИИ — наблюдатель и помощник менеджера.

ИИ умеет:

Анализировать тикеты

Выявлять забытые задачи

Предлагать действия

Делать summary тикетов

Помогать формулировать заметки

Давать советы по приоритетам

Делать утренний обзор

ИИ НЕ имеет:

доступа в интернет

доступа к внешним API

отправки данных наружу

Принцип передачи данных ИИ

ИИ получает только структурированный контекст:

Ticket ID
Status
Priority
Last activity
Notes summary


Не передавать всю БД целиком без необходимости.
